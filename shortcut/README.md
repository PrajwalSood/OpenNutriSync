# Prebuilt `LogFullNutrition` shortcut

`LogFullNutrition-unsigned.shortcut` is generated by `generate_shortcut.py` and contains the
full flow from [../docs/SHORTCUT_SETUP.md](../docs/SHORTCUT_SETUP.md): parse the URL-scheme
JSON payload, log all 39 HealthKit nutrition samples, show a confirmation notification. The
optional dashboard webhook (step 4) is not included — it needs your personal URL and secret;
add it in the Shortcuts app after importing.

## Why you can't just tap the unsigned file

iOS/macOS refuse to import unsigned shortcut files. Signing requires a Mac:

```sh
# for your own devices (signed with your iCloud identity)
shortcuts sign --input LogFullNutrition-unsigned.shortcut \
               --output LogFullNutrition.shortcut

# for public distribution (Apple-server signed; occasionally errors — retry later)
shortcuts sign --mode anyone \
               --input LogFullNutrition-unsigned.shortcut \
               --output LogFullNutrition.shortcut
```

Then double-click `LogFullNutrition.shortcut` on the Mac (imports into Shortcuts and syncs to
your iPhone via iCloud), or AirDrop it to the iPhone.

Note: files signed with the default `people-who-know-me` mode embed your iCloud identity and
only import for your contacts — don't publish those. For sharing with strangers, use
`--mode anyone` or the iCloud-link method in the docs.

## Regenerating

```sh
python3 generate_shortcut.py   # rewrites LogFullNutrition-unsigned.shortcut
```

Edit the `FIELDS` table in the script if Apple adds nutrition types.
